# Анализ демографических и экономических показателей стран (Power BI)

## 📌 Описание проекта
Интерактивный дашборд в Power BI для анализа социально-экономических показателей различных стран мира (уровень рождаемости, смертности, расходы на образование, оборону и уровень безработицы).

## 🛠 Выполненные задачи и навыки
- **Загрузка и очистка данных (Power Query):** Импорт данных из TSV и CSV файлов, исправление опечаток в названиях регионов, приведение типов данных.
- **Моделирование данных:** Связывание таблиц с использованием `LEFT JOIN` и алгоритмов нечёткого соответствия (Fuzzy Matching).
- **Визуализация:** 
  - Карточки с ключевыми метриками (медианный возраст, продолжительность жизни).
  - Сравнительные столбчатые диаграммы (топ-10 стран по рождаемости и смертности).
  - Интерактивная карта расходов на оборону и уровня ожирения по странам.
  - Диаграмма рассеяния (Scatter Plot) для анализа взаимосвязи фертильности и медианного возраста.
- **Аналитическая обработка:** Обработка пропущенных значений `(Blank)`, возникших из-за особенностей связи таблиц, и настройка фильтрации отчёта.
